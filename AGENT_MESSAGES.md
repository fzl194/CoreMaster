# AGENT_MESSAGES

本文档是消息索引，不是完整留言板。

用途：

- 给所有人快速查看“最近有哪些任务发生了新消息”
- 指向真正的任务消息文件：`docs/messages/<task-id>.md`

规则：

- 只追加摘要，不写完整正文
- 每条摘要都必须关联 `task-id`
- 每条摘要都必须带消息文件路径
- 消息 ID 使用时间戳 + 发送方，避免并发撞号
